# Учебные seeded-дефекты (КТ 04)

Приложение `Campus Portal Demo` создано **намеренно** с функциональными ошибками
для практики оформления дефектов. Это не баги production-системы.

| ID | Кратко | Ожидаемое поведение | Фактическое (seeded) |
|---|---|---|---|
| SEED-001 | Пустой пароль при входе | Показать ошибку, не пускать на dashboard | Вход принимается, открывается dashboard |
| SEED-002 | Email без домена (`user@mail`) | Отклонить регистрацию | Регистрация «успешна» |
| SEED-003 | Количество товара = 0 | Показать ошибку валидации | Заказ оформляется как успешный |
