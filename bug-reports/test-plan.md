# Тест-план — КТ 04 (Campus Portal Demo)

## 1. Цель

Проверить учебное веб-приложение **Campus Portal Demo**, выявить и задокументировать
намеренно внедрённые (seeded) функциональные дефекты, оформить баг-репорты и завести
задачи в GitHub Issues как альтернативе Jira.

## 2. Объект тестирования

Локальные HTML/JS-страницы:

- `selenium/fixtures/kt04/index.html` — вход
- `selenium/fixtures/kt04/register.html` — регистрация
- `selenium/fixtures/kt04/dashboard.html` — заказ учебника

Описание seeded-дефектов: `selenium/fixtures/kt04/seeded-bugs.md`.

## 3. Объём работ

В объёме:

- позитивные сценарии входа и заказа;
- негативные проверки пароля, email и количества;
- фиксация дефектов с доказательствами (скриншоты, падения автотестов).

Вне объёма:

- безопасность (XSS/CSRF), производительность, кроссбраузерность (кроме Chrome);
- исправление seeded-багов (жизненный цикл останавливается на статусе Open).

## 4. Стратегия и техники

- Функциональное тестирование по тест-кейсам.
- Автоматизация на Selenium 4 + pytest + Page Object.
- Тесты, проверяющие **корректное ожидаемое** поведение, намеренно FAIL на seeded-багах.

## 5. Среда

| Параметр | Значение |
|---|---|
| ОС | Windows 11 (10.0.26100) |
| Python | 3.13.9 |
| pytest | 8.4.2 |

## 6. Критерии завершения КТ 04

- ≥ 5 тест-кейсов описаны и прогнаны;
- ≥ 3 подтверждённых дефекта с баг-репортами и скриншотами;
- задачи в трекере созданы или явно указаны черновики;
- отчёт `reports/KT04.docx` сформирован.
