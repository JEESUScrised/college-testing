# КТ05 — Обоснование выбора сайта

## Выбранный сайт

**ВДНХ** — `https://vdnh.ru/`, раздел новостей `https://vdnh.ru/news/`.

## Зачем именно этот сайт

1. **Публичный и стабильный** образовательный/культурный портал без обязательной регистрации для чтения новостей.
2. **Реальный пользовательский сценарий**: посетитель открывает главную → переходит в новости → читает карточку → возвращается в ленту → подгружает ещё материалы.
3. **Достаточная сложность для автотестов**: динамическая лента, кнопки подгрузки, карточки со ссылками, отдельные страницы статей.
4. **Совместимость с учебным референсом** преподавателя (структура Selenium / Page Object в духе sa-teach/selenium-tests).
5. **Этические ограничения**: нет нагрузочного теста чужого API; сценарии read-only.

## Бизнес-назначение тестируемой функциональности

Раздел новостей информирует посетителей о событиях и активностях комплекса ВДНХ. Критично, чтобы лента открывалась, карточки были кликабельны, статьи читаемы, а подгрузка «Показать ещё» расширяла список без потери навигации.
