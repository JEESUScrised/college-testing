# Тест-план — КТ 05 (функциональное тестирование VDNH)

## 1. Цель

Проверить ключевой функционал публичного раздела новостей сайта **ВДНХ**
(`https://vdnh.ru/news/`) и оформить комплект тестовой документации.

Референс преподавателя: [sa-teach/selenium-tests](https://github.com/sa-teach/selenium-tests)
(структура Page Object / тест-план; локаторы перепроверены на актуальной вёрстке).

## 2. Объект тестирования

| Элемент | URL / область |
|---|---|
| Главная | `https://vdnh.ru/` |
| Лента новостей | `https://vdnh.ru/news/` |
| Карточка новости | `https://vdnh.ru/news/<id>/` |

Доступность (2026-10-09): сайт отвечает; полный `page load` в Chrome часто зависает на фоновых
ресурсах. Рабочая стратегия: `pageLoadStrategy=none` + явные ожидания DOM.

## 3. Объём (scope)

В объёме:

- открытие главной и раздела новостей;
- отображение заголовка раздела;
- наличие карточек с осмысленным текстом и ссылками;
- открытие статьи, проверка заголовка;
- возврат в раздел новостей;
- подгрузка ленты («Показать ещё»);
- навигация через логотип/меню.

Вне объёма: авторизация, оплата, нагрузка, pixel-perfect, мобильная вёрстка.

## 4. Методы и техники

| Техника | Применение |
|---|---|
| Чёрный ящик | Пользовательские сценарии без знания серверной логики |
| Серый ящик | DOM/CSS-локаторы, URL `/news/<id>`, readyState |
| Белый ящик | **Не применим** к закрытому backend публичного сайта |

## 5. Среда

| Параметр | Значение |
|---|---|
| ОС | Windows 11 |
| Python / pytest / Selenium | 3.13.9 / 8.4.2 / 4.50.0 |
| Браузер | Google Chrome (headed) |
| Стратегия загрузки | `--page-load-strategy=none` |
| Запуск | `scripts/run_kt05_no_vpn.ps1` (без VPN) |

## 6. Критерии входа / выхода

**Вход:** Chrome, `.venv`, зависимости, локальный ChromeDriver, сайт доступен без VPN.

**Выход:** ≥ 8 осмысленных автотестов; документация `docs/kt05/`; скриншоты; отчёт DOCX;
результаты прогонов зафиксированы честно (включая FAIL).

## 7. Риски

- Изменение вёрстки VDNH.
- Тяжёлые скрипты/таймауты renderer.
- Динамический контент — нельзя зашивать конкретные заголовки новостей.
- Подгрузка «Показать ещё» зависит от клиентского JS/XHR (флейк возможен).

## 8. Архитектура автотестов

- Page Object: `selenium/pages/vdnh_pages.py` (`VdnhHomePage`, `VdnhNewsListPage`, `VdnhNewsArticlePage`)
- Тесты: `selenium/tests/test_kt05_vdnh_news.py`
- Общая инфраструктура: `selenium/conftest.py` (без поломки KT01–KT04)
